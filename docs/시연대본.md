# 시연 영상 대본 (2분 30초 안팎)

과제 요구: **세 칸을 차례로 쓰고, 크롬 프로필이 열리며 타이핑 · 게시 · 확인되는 화면** (2~3분)

## 녹화 전 준비
- [ ] 바탕화면 **[운명원 댓글 에이전트]**로 실행 → 상단에 **AI Gemini**, 노란 **리허설 모드** 배지가 보이는지 확인
- [ ] ③ 칸에서 유튜브1(가능하면 2·3도)이 **초록 점**(로그인됨)인지 확인. 아니면 [계정 설정]에서 로그인
- [ ] 개인 정보가 보이지 않게 정리: 다른 브라우저 탭·알림·메신저 끄기, 대시보드 창 하나만 최대화
- [ ] 화면 해상도 1920×1080 권장 (크롬 팝업 1280×900이 대시보드 왼쪽·가운데를 덮고 ③ 칸은 보이게 배치됨)

## 순서 A — 세 칸을 직접 쓰는 기본 시연 (권장)

| 시간 | 화면 | 말할 내용 (자막으로 넣어도 됨) |
|---|---|---|
| 0:00–0:12 | 대시보드 전체 | "유튜브 연애 영상에 맥락에 맞는 댓글을 달아, 읽은 사람이 운명원 연애사주를 보고 싶어지게 만드는 에이전트입니다. 화면은 ①②③ 세 칸입니다." |
| 0:12–0:30 | ① [영상 불러오기] → 목록 | "버튼 한 번으로 이번 주 올라온 연애 영상을 썸네일·제목·채널·날짜와 함께 불러옵니다." **[뜨기 직전]** 탭을 잠깐 눌러 '시간당 조회수' 칩을 보여 줍니다. |
| 0:30–1:00 | ② 영상 하나 클릭 → 분석 → 결과 | "자막과 인기 댓글을 읽고 먼저 영상 속 고민을 한 줄로 정리한 뒤, 이 영상에서만 나온 장면을 짚어 시청자 말투로 씁니다." 밑줄 친 장면, 분홍 '운명원', 아래 **규칙 칩**(40~120자, 링크·해시태그 없음, 지어낸 후기 아님)을 가리킵니다. **말투** 버튼(영크크 등)을 하나 눌러 초안이 바뀌는 것도 보여 줍니다. |
| 1:00–1:05 | ③ [자동 배정] → [댓글 달기 (리허설)] | "처음엔 항상 리허설 모드라, 끝까지 입력만 하고 게시하지 않습니다." |
| 1:05–1:25 | **크롬 팝업**이 대시보드 앞에 뜸 → 댓글 창 → 한 글자씩 입력 → 지움 | 입력 장면은 편집에서 2배속으로 줄여도 됩니다. 오른쪽 ③ 칸의 "입력 중 46/86"도 같이 보입니다. |
| 1:25–2:05 | **리허설 성공 창** → [리얼 모드로 바꾸고 바로 게시] → 크롬 팝업: 입력 → [댓글] → **내 댓글 분홍 테두리** | "리허설이 성공하면 그대로 리얼로 올릴지 묻습니다." 핵심 장면입니다. 분홍 테두리로 표시된 **내 댓글**이 2~3초 보이게 둡니다. |
| 2:05–2:15 | 대시보드 ③ '게시 완료 · 댓글 보기' → 클릭해 유튜브에서 확인 | "게시와 확인까지 끝났습니다. 상단 배지가 빨간 리얼 모드로 바뀌었습니다." |
| 2:15–2:35 | 같은 영상이 '댓글 완료'로 잠긴 것 → 아래 **기록** 표 | "같은 영상에는 다시 달 수 없고, 하루 상한도 서버가 막습니다. 어느 영상에, 어떤 계정·말투로, 무슨 댓글을, 성공했는지가 시간순으로 남고 CSV로 내보낼 수 있습니다." |

## 순서 B — ▶ 전체 자동으로 보여 주기 (가점 어필, 30~40초 추가)
1. 상단 **[▶ 전체 자동]** → 가져올 영상 '최신 연애 영상', 개수 **2** → [시작]
2. ①②③ 칸이 저절로 움직임: 불러오기 → 영상 선택 → 초안 → 자동 배정(유튜브1 → 유튜브2) → 크롬 팝업에서 입력
3. 첫 리허설 성공 창 → **[리얼 모드로 바꾸고 이 댓글부터 실제 게시]**
4. 두 번째 영상은 다른 계정으로 자동 게시 → 상단 막대 "2 / 2 · 끝났어요 · 게시 2"
- 말할 내용: "버튼 하나로 영상 선택부터 게시까지 이어지고, 한 영상엔 한 계정만, 계정은 돌아가며 배정됩니다."
- 순서 A 끝에 붙이거나, 시간이 부족하면 A의 1:05 이후를 B로 대체해도 됩니다.

## 녹화 방법
- **자동 녹화(ffmpeg)**: 이 PC에는 ffmpeg가 설치돼 있어 아래 명령으로 화면 전체를 녹화할 수 있습니다. 끝낼 때는 그 창에서 `q`를 누릅니다.
  ```
  ffmpeg -f gdigrab -framerate 30 -i desktop -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p 시연.mp4
  ```
- 또는 Windows **캡처 도구(Win+Shift+R)**로 화면 영역을 지정해 녹화할 수 있습니다. (Win+Alt+R은 창 하나만 녹화되어 크롬 팝업이 빠질 수 있음)

## 올리기
- 구글 드라이브: 업로드 → 공유 → 일반 액세스 **"링크가 있는 모든 사용자"** → 링크 복사
- 또는 유튜브: 업로드 → 공개 상태 **"일부 공개"** → 링크 복사
- 제출 전 **로그인하지 않은 창(시크릿 창)**에서 링크가 재생되는지 꼭 확인합니다.
