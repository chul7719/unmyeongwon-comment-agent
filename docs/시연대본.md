# 시연 영상 대본 (2분 30초 안팎)

녹화 도구: Windows `Win + Alt + R`(Xbox Game Bar)는 창 하나만 녹화하므로, 크롬 프로필 창까지 담으려면 **OBS Studio의 '디스플레이 캡처'**를 권장합니다. 해상도는 1920×1080을 권장합니다.

## 녹화 전 준비
- [ ] `start.bat`로 실행해 두고, 상단에 **AI 이름(Gemini 등)**이 보이는지 확인합니다.
- [ ] [계정 설정]에서 유튜브1(가능하면 2, 3도)이 **로그인됨**(초록 점)인지 확인합니다.
- [ ] `rehearsal.bat`로 한 번 연습해 타이핑이 정상인지 확인한 뒤, 다시 `start.bat`로 실행합니다.
- [ ] 알림과 메신저를 끕니다. 대시보드는 크롬 창 하나에 최대화해 둡니다.

## 순서

| 시간 | 화면 | 말할 내용(자막으로 넣어도 됨) |
|---|---|---|
| 0:00–0:15 | 대시보드 전체 | "유튜브 연애 영상에 맥락에 맞는 댓글을 달아, 읽은 사람이 운명원 연애사주를 보고 싶어지게 만드는 에이전트입니다. 화면은 ①②③ 세 칸입니다." |
| 0:15–0:35 | ① [영상 불러오기] 클릭 → 목록 | "버튼 한 번으로 이번 주 올라온 연애 영상을 썸네일, 제목, 채널, 날짜와 함께 불러옵니다." **[뜨기 직전]** 탭을 잠깐 눌러 시간당 조회수 칩을 보여 주고 다시 최신으로 돌아옵니다. |
| 0:35–1:05 | ② 영상 하나 클릭 → 분석 단계 → 결과 | "자막과 인기 댓글을 읽고, 먼저 영상 속 고민을 한 줄로 정리합니다. 그다음 이 영상에서만 나온 장면을 짚어 시청자 말투로 댓글을 씁니다." 밑줄 친 장면 부분과 분홍색 '운명원', 아래 **규칙 칩(40~120자, 링크·해시태그 없음, 지어낸 후기 아님)**을 가리킵니다. |
| 1:05–1:15 | (선택) 링크 입력 칸에 다른 영상 링크 붙여넣기 | "링크를 직접 넣어도 됩니다." 시간이 부족하면 생략합니다. |
| 1:15–1:20 | ③ 계정 [자동 배정] 또는 [유튜브1] → [댓글 달기] | "버튼을 누르면 유튜브1 크롬 프로필이 열립니다." |
| 1:20–2:05 | **크롬 프로필 창**: 영상 → 스크롤 → 댓글 창 → 한 글자씩 입력 → 게시 → 내 댓글 테두리 표시 | 화면이 크롬 창으로 넘어가는 장면이 핵심입니다. 입력되는 동안 말하지 않아도 됩니다. 마지막에 분홍 테두리로 표시된 **내 댓글**이 보이게 둡니다. |
| 2:05–2:20 | 대시보드로 돌아와 ③ '게시 완료 · 댓글 보기' → 클릭해 유튜브에서 확인 | "게시와 확인까지 끝났습니다. 댓글 링크로 바로 열 수 있습니다." |
| 2:20–2:35 | 같은 영상을 다시 골라 버튼이 잠긴 것 보여 주기 → 아래 **기록** 표 | "같은 영상에는 두 번 달 수 없고, 하루 상한도 서버가 막습니다. 어느 영상에 어떤 계정으로 무슨 댓글을 달았는지, 성공했는지 실패했는지가 시간순으로 남고 CSV로 내보낼 수 있습니다." |

## 팁
- 처음 고른 영상의 초안이 마음에 들지 않으면 [다시 쓰기]를 누르거나 직접 고친 뒤 녹화합니다.
- 실패 장면을 보여 주고 싶다면 로그인하지 않은 프로필(예: 유튜브3)로 한 번 눌러, 실패 이유와 캡처가 남는 것을 짧게 넣어도 좋습니다. 운영 규칙 항목에서 가산이 될 수 있습니다.
- 업로드: 구글 드라이브 '링크가 있는 모든 사용자' 또는 유튜브 '일부 공개'로 올린 뒤, **로그인하지 않은 창(시크릿 창)에서 재생되는지** 확인합니다.
